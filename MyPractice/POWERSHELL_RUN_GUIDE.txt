PART 2: PRO-FEATURE — PROMPT CACHING (Cells 63–67)
--------------------------------------------------------------------------------
File:
  [MyPractice\week2\demo_prompt_caching.py]

Function Name:
  lec42_day1_prompt_caching_demo()

Simple Explanation (What it does):
  1. Loads the entire Hamlet book (~191,726 characters, ~48,000 tokens).
  2. Attaches the static text as a SYSTEM prefix.
  3. Call 1 (Cold Cache): Model processes all 49,696 tokens from scratch.
  4. Call 2 (Warm Cache): Model reuses the cached prefix!
     Reads 49,536 tokens directly from memory at ~50% discounted cost and 2x faster latency!

When to Run:
  When you want to see how prompt caching saves money and latency on large documents.

PowerShell Command:
  & "d:\AlamProgrammingPractice\AI_LLM Engineer\MyPractice\.venv\Scripts\python.exe" "d:\AlamProgrammingPractice\AI_LLM Engineer\MyPractice\week2\demo_prompt_caching.py"

Expected Output:
  - Step 1: Text loaded (~47,931 tokens)
  - Step 5 (Cold): Input: 49,696 | Cached: 0 | Cost: ~0.7486 cents | Latency: ~2.66s
  - Step 6 (Warm): Input: 49,693 | Cached: 49,536 | Cost: ~0.3773 cents | Latency: ~1.51s
  - Summary: 49.6% cheaper on warm call!
